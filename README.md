# SmartMeal

Мультиплатформенное приложение для планирования питания, ведения дневника и работы с рецептами и
продуктами — с учётом личных целей, семейного режима и автоматического составления рациона.

Kotlin Multiplatform-проект с общим UI, бизнес-логикой, сетевым слоем и локальным кэшем для Android
и iOS. SmartMeal задуман как практичный инструмент на каждый день и как pet-проект / портфолио-кейс
с акцентом на Clean Architecture, MVI и современный KMP-стек.

Проект в активной разработке: функциональность и UI дополняются по мере роста кодовой базы.

## Архитектура 🏗️

Проект построен на **Clean Architecture** и **MVI** с разделением на слои:

- **Presentation** — Compose Multiplatform, Decompose-компоненты, UI-модели и маппинг
- **Domain** — use cases, доменные модели, правила планировщика и расчёта нутриентов
- **Data** — репозитории, Ktor + Supabase, Room, DataStore, синхронизация каталога

Функциональность сгруппирована по feature-модулям внутри `shared`: у каждой области (`recipes`,
`ingredients`, `diary`, `mealplan`, `settings` и др.) свои `data/`, `domain/` и `presentation/`
пакеты. Зависимости собираются через **Koin**.

Основные вкладки приложения: **Рецепты**, **Продукты**, **Дневник**, **Планирование**, **Настройки
**.
