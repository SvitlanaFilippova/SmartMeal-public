> SmartMeal — мультиплатформенное приложение для планирования питания, ведения дневника и организации семейного рациона.
>
> Приложение помогает объединить рецепты, цели питания, автопланирование, покупки и повседневные привычки в одной связанной системе.
>
> SmartMeal учитывает не только калории, но и реальные сценарии домашней кухни: готовку на несколько дней, остатки еды, фиксированные приёмы пищи и разные цели членов семьи.

---

Kotlin Multiplatform-проект с общим UI, бизнес-логикой, сетевым слоем и локальным кэшем для Android и iOS.

SmartMeal задуман как практичный инструмент для повседневной жизни — с фокусом на снижение ручной рутины вокруг питания.

Проект находится в активной разработке: функциональность и UI продолжают развиваться по мере роста продукта.

## Архитектура 🏗️

Проект построен на **Clean Architecture** и **MVI** с разделением на слои:

- **Presentation** — Compose Multiplatform, Decompose-компоненты, UI-модели и маппинг
- **Domain** — use cases, доменные модели, логика планировщика, расчёта нутриентов и персонализации рациона
- **Data** — репозитории, Ktor + Supabase, Room, DataStore, синхронизация каталога

Функциональность сгруппирована по feature-модулям внутри `shared`: у каждой области (`recipes`, `ingredients`, `diary`, `mealplan`, `settings` и др.) свои `data/`, `domain/` и `presentation/` пакеты.

Зависимости собираются через **Koin**.

Основные вкладки приложения:

- **Рецепты**
- **Продукты**
- **Дневник**
- **Планирование**
- **Настройки**
